# App Run Guide

Source: [packages/examples/app/README.md](../../../packages/examples/app/README.md).

## What

Setup and local verification instructions for the desktop example.

## Why

Consumers must supply their own deployed issuer rather than inherit a previous deployment.

## How

Documents the public app client, dynamic loopback redirect, keychain refresh storage, environment overrides and npm/Cargo commands. The checked-in issuer is a placeholder; mobile auth is not implemented by the desktop scaffold.
